# Public Transit Tracker assets

This directory owns the public MBTA page shell, styles, privacy notice, manifest, and icon. Edit those files here. The browser script `app.js` is generated from editable source in the private Jianzhao site repository; its release workflow updates that script. Never treat the minified public script as the editable source. The Cloudflare Worker owns API proxying, travel requests, visit recording, and private credentials.

The page is a responsive Leaflet tracker for MBTA and EZRide routes, stops, vehicles, alerts, and travel-time context. MBTA also supplies stop predictions; EZRide stop popups say when reliable live arrival times are unavailable. Preserve the existing `/mbta/` URL, relative asset paths, privacy link, accessible controls, mobile layout, and Worker requests when changing public markup or styles. The single route picker includes one EZRide entry sorted alongside other buses via the private browser source; the public page shell and styling remain shared. The optional `#serviceSummary` sits inside the shared `#panelDetails` section and appears only when Details is expanded. Its dynamic `#serviceSummaryText` row uses a blue solid line for an active EZRide period; a second gray dashed line labeled "Service at other times" explains the inactive geometry. When no period is active, only the gray status row is shown. Current period lines and stops use blue `#6BAED6`; other periods remain visible in light gray. The stop marker uses `--stop-color` so the inactive CSS state can override it. Browser-delivered files and the domain-restricted basemap key are inspectable; other provider credentials belong only in Worker secrets.

`index.html` uses one `window.__APP_VERSION__` value for both CSS and JavaScript cache-busting. Bump it when publishing CSS changes. The private JavaScript release workflow updates it when a new generated script differs from the current public script. Icons and the manifest do not use this value; verify their browser caching separately after changing them. Check that both versioned CSS and JavaScript URLs resolve after deployment.

The public Pages workflow deploys only runtime files. Documentation in this directory is kept in Git and excluded from the Pages artifact. Test desktop and mobile presentation, route selection, map rendering, live vehicles, stop details, privacy navigation, and the Worker health/route behavior after changes. Coordinate private JavaScript and Worker changes with their own source repository and release checks.

For a static-file edit, review the public Pages workflow's runtime allowlist and its deployment result. For a browser-logic edit, follow the private repository's MBTA release guide: build there, confirm the generated script and cache version were updated here, then check the public Pages deployment. Local static serving can check layout, but Worker origin policy may prevent complete API testing from a local host; confirm route and travel behavior on the deployed site.

## Experimental network view

The shell retains `#networkStatus` for private-source All routes mode, without a standalone toggle. The existing route picker has an “All routes” entry in its own `.route-group`, reusing the standard adjacent-group divider before Subway & Light Rail. Normal stop/vehicle popups offer “Show all routes”; full route overlays inside network mode offer “Show this route”, preserving the camera.

Thin translucent subway/light-rail lines form the bottom background (opacity 0.20–0.28). Smaller bus/EZRide, commuter rail and ferry dots have no arrows and fill opacity 0.65. Larger subway/light-rail circles retain arrows and render above those compact dots. All background circles share one Canvas above route lines, so upper canvases cannot block lower circles; rapid paths are brought forward within its paint/hit-test order. Sizes update during fractional zoom. Clicking any observation expands its entire route through the original single-route shapes, stations, full vehicle icons, layout, popups and polling. Duplicate background observations from that route are hidden after loading; other routes remain live. Empty-map click or choosing All routes clears the expanded route; station/vehicle inspection, popup close and panning retain it. `.network-*` CSS covers actions and the complete overlap chooser; `.is-network-view` hides normal summary/details. Modules remain inside generated `app.js`, so the Pages allowlist is unchanged. Test desktop/mobile, opacity/paint/click order, zoom scaling, route expansion, stops, popup switching and delayed-load cancellation. Deploy the private Worker endpoints before publishing.
