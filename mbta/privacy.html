MBTA Tracker Privacy

When you open or reload the tracker, it counts one page view for site usage statistics. Page views from the same IP address within a 30-minute period share one record with first and last visit times and a view count. The record contains the IP address, approximate country/region/city and network organization, browser, operating system, device type, page path, referring website, language, and screen dimensions.

These records are stored in a private Cloudflare database. They can be viewed only through the site owner's Cloudflare account and are not shown to other visitors. The tracker does not automatically delete visit records. Storage usage is monitored and this policy may be updated if retention changes.

Location based on IP is approximate. The tracker does not record your precise GPS location in its visit records.
